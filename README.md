# Dryfruit Bazar

A simple e-commerce-style website for selling dry fruits and nuts. This project includes product pages, a shopping cart, testimonials, contact, about, and login/registration sections.

## Features
- Product catalog with multiple dry fruit categories
- Individual product pages
- Shopping cart functionality
- Customer testimonials section
- About and contact pages
- User login and registration pages
- Responsive design for desktop and mobile browsing

## Project Structure
- `index.html` – homepage
- `Products.html` – main product listing page
- `about.html` – about section
- `contact.html` – contact page
- `testimonials.html` – customer reviews
- `login.php` and `login` – login functionality
- `register.php` and `register/` – registration pages
- `products` – individual product pages and styles
- `images` – project images
- `style.css` and product-specific CSS files – styling

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- Bootstrap-style custom frontend layout (as used in project files)

## How to Run
1. Place the project in a local web server environment such as XAMPP, WAMP, or MAMP.
2. Start the Apache server.
3. Open the project in your browser using:
   - `http://localhost/your-project-folder/`
4. For PHP-based login and registration features, ensure PHP is enabled and the server is running properly.

## Notes
- This project is a frontend and PHP-based web application.
- Some pages may require a working local server for PHP functionality.
- Product/cart behavior may depend on JavaScript files such as `addtocart.js`.
